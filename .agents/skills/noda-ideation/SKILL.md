# 野田クリスタル式 企画生成

マヂカルラブリー・野田クリスタルさんへのヒアリングから体系化した企画思考法で、お題から新しい商品・サービスの企画案を3案つくるスキル。

## スコープ

**このスキルは「一旦の企画案を3案出す」ところまで**。その先のブラッシュアップ（出してみて反応を見るトライアンドエラー）はスコープ外。3案提示で終了する。

## 全体フロー

お題の受け取り → 評価軸の捉え直し → 種の振り絞り → 疑う（既存調査） → 妄想で育てる → 最終チェック → 3案提示

## 野田メソッドの核（全ステップの判断基準）

1. **お題なくしてアイデアなし** — お題は絶対必要。バクッとしたお題はまず捉え直す。
2. **真っ直ぐ戦ったら勝てない** — ストレートな評価軸で競争しない。評価軸をズラすか、なくす（点数のつけようがないものにする）。野田さんのM-1優勝ネタは「優勝した漫才」ではなく「点数のつけようがないから競えなかったもの」。
3. **なるべく無理そうなお題に挑む** — 難しいほど競争相手が少ない。根本は「競争したくない」。
4. **法則を見せない** — 作ったものにロジック・パターンを感じさせない。前回と同じ型は使わない。
5. **アイデアは天から降ってこない** — 締切・強制力の中で振り絞る地道な作業。「振りかぶらず、間に合わせる」。
6. **クリエイトではなくエディット** — ゼロイチはおこがましい。すべては既存のAとBの組み合わせ。どんなに廃れた技術・もの・アイデアも生かせる（横井軍平の「枯れた技術の水平思考」）。
7. **まず疑う** — 「もうあるんじゃね？」を必ず調べる。あっても降りない。(a) 水平思考で別用途にスライドする、(b) 既存の「普通の使い方」をフリにして真逆へ行く（扇風機は乾かす・涼むが普通→PCのファンになる）。みんなが降りる場所の先にこそヒントがある。
8. **組み合わせの距離感** — 自然すぎる組み合わせは×、遠すぎるのも×。「意外だけど確かに」が基準線。ただしそれ一辺倒でもない。
9. **崩すが、崩し一辺倒にならない** — 「こいつ毎回崩してるな」と思われたら負け。メタ視点で自分の法則化を監視する。
10. **自分の中で妄想で育てる** — アイデアは人に話した時点でしぼむ（野田さんが引く桜井政博さんの言葉）。世に出た後のシナリオまで妄想して、機が熟したら形にする。

## 手順

### Step 0: お題の受け取り

- ユーザーの依頼からお題を特定する。**お題がなければユーザーに確認する**（お題なくしてアイデアなし。勝手にお題を発明しない）。
- 企画主体のアセット（高頻度でやっていること・大量に溜まっているもの）と「元々作りたい方向性」が提供されていれば控える。提供がなければお題ルートのみで進める。

### Step 1: 評価軸の言語化と捉え直し（3方向）

まず「このお題にストレートに応えた場合の評価軸A」を1行で言語化する（例: おしゃれな服→おしゃれさ）。そのうえで、**3案それぞれに異なる捉え直しの型**を割り当てる:

- **型1 ズラす**: 評価軸Aを別の評価軸Xに置き換える
- **型2 なくす**: 評価・採点・比較が成立しない、競争にならないものにする
- **型3 フリ返し**: 「このお題、普通はこう応えるよね」を言語化し、それをフリにして真逆・別用途へ行く
- **型4 アセット×ニーズ**（アセット情報がある場合のみ）: 高頻度アセット × 元々作りたい方向 → 気付きから種を出す。型1〜3のどれかと差し替える

各方向とも「なるべく無理そう・勝てなさそう」な側に倒す。楽に勝てそうな方向が出たら疑う。

### Step 2: 種の振り絞り（エディット）

- 各方向につき**最低5個、合計15個以上**の種をまず出し切る。天から降ってこないので、数のノルマが締切の代わりの強制力になる。1〜2個で満足しない。
- 種はすべて「A × B → こうなる」のエディット形式で書く。ゼロイチの発明を書かない。
- 素材には枯れた技術・廃れたフォーマット・定番すぎて誰も見ていない仕組みを積極的に混ぜる。
- 出し切ってから距離感で選別する: 自然すぎ×／遠すぎ×／「意外だけど確かに」○。
- 3案の候補を選ぶとき、同じ崩し方・同じズラし方が並んでいないか確認する（法則を見せない）。

### Step 3: 疑う（必須・スキップ禁止）

- 候補3案それぞれについて「もうあるんじゃね？」「もうやられてるんじゃね？」をWeb検索で調べる。Web検索が使えない環境なら、自分の知識の範囲で既存の類似例を具体的に挙げて検証する。
- 既存の類似が見つかっても降りない:
  - (a) **水平思考**: 同じ仕組みを別の用途・別の客・別の文脈にスライドできないか
  - (b) **フリに使う**: 既存のやり方を「普通」として提示し、その真逆を行けないか
- 既存との違いを一言で言えない種は捨て、Step 2の種リストから繰り上げる。

### Step 4: 妄想で育てる

- 各案について「世に出た瞬間のシナリオ」を妄想する: 誰が最初に食いつくか、どこでどう話題になるか、どんな声が上がるか。
- シナリオが具体的に描けない案は、種から選び直す。

### Step 5: 野田フィルター（最終チェック）

3案すべてについて確認。1つでも×なら該当ステップに戻る:

- [ ] 評価軸Aのフツウの土俵で戦っていない
- [ ] ゼロイチでなくA×Bのエディットになっている
- [ ] 組み合わせが自然すぎず遠すぎない（「意外だけど確かに」がある）
- [ ] 「もうある」を実際に調べ、既存との違いが一言で言える
- [ ] 3案が同じ型で作られていない（崩し一辺倒・ズラし一辺倒の禁止）
- [ ] 狙いのロジック・法則感が表から見えすぎていない
- [ ] 妄想シナリオが具体的に描けている
- [ ] 造語は3案全体で1〜2個まで。タイトル・説明は一般語で書く

## 出力フォーマット

途中の思考（種リスト等）は最終出力に含めず、以下だけを提示する:

```
# 「＜お題＞」の企画3案（野田クリスタル式）

## 案1「タイトル」（型: ズラす/なくす/フリ返し/アセット）

**一言コンセプト**: 〜
**捉え直し**: 評価軸「A」→ どう捉え直したか
**エディット**: 何 × 何 の組み合わせか（＋なぜ「意外だけど確かに」か）
**疑いの結果**: 既存の類似 → どう違うか／どうフリに使ったか
**妄想シナリオ**: 世に出た瞬間の絵（2〜3文）

## 案2・案3（同形式）

## 3案の並び
各案の型と狙いの違いを2〜3行で。最初に試すならどれかを1つ推薦。
```

## 注意

- Step 3の「疑う」を省略しない（このメソッドの背骨）
- 3案を同じパターンで量産しない
- 企画名・コンセプトに凝った造語やカタカナ新語を並べない（一般語で）
- ブラッシュアップ（出して反応を見る）に踏み込まない
